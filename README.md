## 🚀 Quick Start - Deploy to GitHub Pages

### Step 1: Upload Files to Repository

1. Go to GitHub: https://github.com/tutarzeliha-ctrl/-tutarzeliha-ctrl.github.io
2. Click **"Add file"** → **"Upload files"**
3. Drag & drop all files from this portfolio folder
4. Commit changes (add message: "Initial portfolio setup")

**File structure to upload:**
```
index.html
projects.html
about.html
contact.html
README.md
css/style.css
projects/fraud-detection.html
projects/data-quality.html
projects/churn-prediction.html
```

### Step 2: Enable GitHub Pages

1. Go to **Settings** → **Pages** (left sidebar)
2. Under "Source":
   - Branch: `main`
   - Folder: `/ (root)`
3. Click **Save**

Your site will be live at: **https://tutarzeliha-ctrl.github.io** ✅

## 🎨 Customization

### Update CV Link
All pages link to your CV. Replace in every page:

```html
<a href="assets/Zeliha_Tutar_Analytics_Engineer_CV.docx">Download CV</a>
```

Or update the file path if you store CV elsewhere.

### Update GitHub Links
Replace `tutarzeliha-ctrl` with your GitHub username in:
- Navigation bar
- All project cards
- Footer
- Contact page

Example:
```html
<a href="https://github.com/YOUR-USERNAME/fraud-detection">View GitHub</a>
```

### Update LinkedIn & Email
Replace in all pages:
- `ttutarzeliha@gmail.com` → Your email
- `linkedin.com/in/zeliha-tutar-35a3013aa/` → Your LinkedIn

### Add Profile Photo
1. Save photo as `assets/profile.jpg`
2. Uncomment image in `about.html`:
```html
<img src="assets/profile.jpg" alt="Zeliha Tutar" class="rounded-circle">
```
