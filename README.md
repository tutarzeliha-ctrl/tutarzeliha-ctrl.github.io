# Zeliha Tutar – Portfolio Website

Personal portfolio site for analytics and data engineering projects.

**Live site:** https://tutarzeliha-ctrl.github.io

## Pages

- `index.html`: home page with the featured projects
- `projects.html`: all projects; every card links to a public GitHub repository
- `projects/`: one detail page per project (what it does, what is in the repo, limitations)
- `about.html`: background and experience
- `contact.html`: contact details
- `css/style.css`: custom styles on top of Bootstrap 5
- `assets/`: CV (PDF)

## Featured project

[realtime-cdc-lakehouse](https://github.com/tutarzeliha-ctrl/realtime-cdc-lakehouse):
PostgreSQL → Debezium → Kafka → DuckDB/Parquet → dbt → Airflow, running locally in Docker.

## Notes

The projects are portfolio work, built locally or on free tiers and mostly on
synthetic data. Numbers appear on the site only where they were measured.

Hosted with GitHub Pages from the `main` branch.
