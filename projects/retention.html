E-Commerce Retention Analytics

dbt Core → BigQuery → Streamlit, with a churn alert script

Portfolio project · runs locally · synthetic data

What it does

dbt staging and mart models turn synthetic e-commerce orders into customer-level retention metrics. dbt tests check keys, a snapshot tracks customer changes and a Python script prepares webhook payloads for customers at risk of churning.

What is in the repository

  • models/staging/ and models/marts/dim_customers.sql: dbt models with tests
  • snapshots/customers_snapshot.sql: dbt snapshot
  • .github/workflows/dbt_ci.yml: CI workflow
  • eda_analysis.py and charts in assets/
  • app.py: Streamlit app

Limitations

  • Synthetic data, so revenue and order figures in the README are illustrative only.
  • Build artefacts (target/, a DuckDB file) are still committed.
