Local Lakehouse Pipeline with Simulated CDC

A robust local data engineering project demonstrating simulated database changes, incremental ingestion, checkpoint-based recovery, data quality checks, and DuckDB analytics over Parquet.

Python PostgreSQL DuckDB Parquet Pytest

Project Overview

This project implements a reliable local lakehouse pipeline designed to process operational database mutations gracefully while enforcing strict data quality and automated test verification. It avoids unnecessary tool bloat to focus on core data engineering reliability principles.

Key Engineering Features

  • Simulated CDC & Incremental Ingestion: Tracks operational changes (INSERT, UPDATE, DELETE) and resumes from state using persistent checkpoints.
  • Idempotency & Deduplication: DuckDB primary-key merge logic ensures re-running batches does not duplicate records in the Silver layer.
  • Crash Recovery & Fault Tolerance: Validated via automated tests ensuring seamless recovery without data loss upon system interruption.
  • Data Quality & Quarantine Layer: Malformed records (e.g., negative amounts) are isolated in a dedicated quarantine Parquet layer.
  • Automated Testing: Comprehensive pytest suite covering incremental logic, idempotency, and crash recovery.

Architecture Workflow

PostgreSQL Source DB → CDC Simulation & Ingestion Module → Silver Parquet & Quarantine Layers → DuckDB Analytics Engine.
