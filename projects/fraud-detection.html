Real-Time Fraud Detection (in progress)

Python producer → Kafka → PySpark Structured Streaming → PostgreSQL → Streamlit

Portfolio project · runs locally · synthetic data

What it does

A Python producer generates synthetic payment transactions and sends them to Kafka. A PySpark Structured Streaming job parses the events with a fixed schema and writes each micro-batch to PostgreSQL. A Streamlit dashboard reads the stored transactions.

What is in the repository

  • producer.py: synthetic transaction generator
  • spark/streaming_processor.py: Kafka → PostgreSQL streaming job (foreachBatch)
  • prefect/flows.py: Prefect flow
  • docker-compose.yml: Kafka (KRaft) and PostgreSQL
  • app.py: Streamlit dashboard
  • tests/test_processor.py: unit tests for the processor

Limitations

  • Fraud rules are not implemented yet: the job stores every transaction; scoring is the next step.
  • Synthetic data; latency was not measured.
  • Runs on a local Docker setup only.
