Supply Chain Delay Predictor

Kafka → PySpark ML → LLM Agents

82% Accuracy

The Problem

Global supply chains face constant disruptions due to unexpected weather, port congestion, and logistical bottlenecks. Traditional reactive tracking systems only report delays after they occur, costing companies millions in operational inefficiencies and failing to provide actionable mitigation steps in real time.

The Solution

An end-to-end predictive pipeline that ingests live shipment telemetry via Kafka, processes features at scale using PySpark ML to forecast delivery risks with 82% accuracy, and integrates LLM agents to automatically generate root-cause analysis and operational mitigation strategies.

Architecture

Kafka (Telemetry Streams) → PySpark ML (Risk Classification Pipeline) → LLM Agents (Actionable Insights)

Key Features

  • ✓ Real-Time Ingestion: Continuous telemetry streaming using Apache Kafka.
  • ✓ Scalable Machine Learning: Distributed model training and inference via PySpark ML.
  • ✓ Automated Reasoning: LLM agents summarizing risk factors and operational impacts.
  • ✓ Proactive Alerting: Early warning system providing actionable mitigation insights.

Business Impact

6-hour early warning system: This project empowers logistics teams to anticipate delays hours before they cascade, optimizing inventory buffers, reducing demurrage costs, and ensuring exceptional service reliability.

Tech Stack
