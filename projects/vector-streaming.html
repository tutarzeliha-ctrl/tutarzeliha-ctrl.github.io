Vector Streaming & ChromaDB

Kafka → Sentence-Transformers → ChromaDB → Streamlit

Portfolio project · runs locally · synthetic data

What it does

A producer sends text events to Kafka. A consumer creates 384-dimensional embeddings with the all-MiniLM-L6-v2 model and upserts them into a persistent ChromaDB collection. A Streamlit app shows collection counts and recent event metadata.

What is in the repository

  • producer.py and consumer_vector_stream.py: streaming and embedding
  • cdc_producer.py and cdc_consumer.py: a CDC-style variant
  • vector_analytics_dbt/: a dbt project with one staging model over the event stream
  • docker-compose.yml: Kafka, Zookeeper, PostgreSQL
  • app.py: Streamlit dashboard

Limitations

  • No requirements.txt yet; dependencies are listed in the README.
  • The dbt folder still contains the default example models.
  • Throughput was not measured.
