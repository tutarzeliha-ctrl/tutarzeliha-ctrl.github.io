Agentic Data Quality (prototype)

Streamlit + Groq (LLM) + Pandas, synthetic data

Portfolio project · runs locally · synthetic data

What it does

A prototype that explores how an LLM can support data quality work. Rule-based checks run first; the LLM is then asked to interpret the results. A Streamlit dashboard shows pipeline metrics.

What is in the repository

  • app.py: Streamlit dashboard
  • agents/quality_agent.py, agents/multi_agents.py: checks and LLM calls
  • generate_data.py, utils/data_generator.py: synthetic data
  • utils/slack_alert.py: Slack webhook helper
  • pipelines/prefect_pipeline.py: Prefect pipeline

Limitations

  • Synthetic data only; not tested against a real warehouse.
  • The Slack alert has not been verified against a live workspace.
  • Remediation in the app is simulated.
