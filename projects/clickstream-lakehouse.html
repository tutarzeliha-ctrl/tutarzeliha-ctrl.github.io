Streaming Clickstream Lakehouse

Apache Flink SQL → Apache Paimon → MinIO (S3-compatible)

Portfolio project · runs locally · synthetic data

What it does

An experimental setup for a streaming lakehouse: Flink SQL writes clickstream events into an Apache Paimon table stored on MinIO. Most of the work was configuring the Flink catalog, the S3 connection and the Paimon connector.

What is in the repository

  • docker-compose.yml: Flink JobManager/TaskManager and MinIO
  • producer.py: clickstream event generator
  • paimon_streaming_job.sql: Flink SQL job
  • setup_paimon.py, fix_hadoop.py, fix_paimon.py: setup and connector fixes

Limitations

  • Experimental: connector JAR files must be copied into the Flink container by hand.
  • The dbt folder is only a scaffold.
  • Event volumes were not measured.
